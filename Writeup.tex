\section{Problem 2}
 \begin{tcolorbox}
        \textbf{Problem Statement:}\\
        Perform a convergence analysis on the solver you wrote in the previous problem. Show it has $\mathcal{O}(\Delta x ^2)$ convergence.
    \end{tcolorbox}
    
    \textbf{Solution:}
    The small absolute error in a refined grid is a good indicator of convergence, but to have confidence in the finite difference solver, it needs to show $\mathcal{O}(\Delta x ^2)$ order convergence. Running the solver for a variety of grid sizes and plotting the $L_2$ error between the analytical solution and the exact solution, the finite difference solver demonstrates just that in each of $u$, $v$ and $p$.
            \begin{figure}[H]
                    \begin{centering}
                        \centering
                            \includegraphics[scale=.75]{Images/convergence_plot.png}
                            \caption{Relative error in finite difference approximations follow second order convergence.}
                            \label{fig: u_convergence}
                    \end{centering}
                \end{figure}
